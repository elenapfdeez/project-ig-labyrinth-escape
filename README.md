**Final project for the Computer Graphics course (Computer Engineering Degree, UGR).** 
Video game prototype focused on labyrinth exploration and escape.

---

## ⚙️ Características Técnicas

Durante el desarrollo de este prototipo en Godot, he implementado las siguientes mecánicas y efectos:

- **Programación del personaje:** Lógica de movimiento, físicas y control del jugador.
- **Gestión de estado:** Sistema de control de vida del personaje y mecánica de reinicio del nivel.
- **Apartado audiovisual:** Integración de texturas para el entorno y música para mejorar la ambientación.
- **Efectos Visuales y Shaders:** 
  - Efectos inmersivos mediante **shaders** (brillo de la llave).
  - Añadido de niebla.
  - Luz programada para simular el fuego de las antorchas.

## 🛠️ Tecnologías utilizadas
- Godot Engine
- GDScript
